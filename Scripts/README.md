# Scripts

En esta infraestructura no fue necesario crear scripts de automatización.

La mayor parte de la configuración se realizó directamente en el FortiGate, el switch y los servidores, utilizando la interfaz gráfica y comandos de configuración cuando fue necesario.

Los comandos y pruebas utilizados durante el laboratorio están documentados en las demás secciones del repositorio junto con sus evidencias.
